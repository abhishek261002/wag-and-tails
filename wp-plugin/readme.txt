=== Wag & Tails ===
Requires at least: 6.2
Requires PHP: 7.4
Stable tag: 1.11.3
License: GPLv2 or later

Home pet grooming website for Wag & Tails: city-wise packages and prices, online booking with Razorpay or pay after service, booking desk for staff, customer accounts with reward points, pet insurance enquiries, dog walking requests and a WooCommerce store.

== Installation ==
1. Install and activate WooCommerce (for the store).
2. Plugins > Add New > Upload Plugin > choose wag-and-tails.zip > Install > Activate.
3. The plugin creates a page called "Wag & Tails" and makes it your home page (if you had no static home page).
4. Open WordPress menu "Wag & Tails" > Open the admin panel, and fill in Settings.

== Logins ==
* Admin: your WordPress administrator login.
* Booking staff: created in the admin panel > Booking staff.
* Customers: create their own account with their mobile number.

== Moving from BookingPress ==
Admin panel > Import from BookingPress. Scan, match services and form fields, then Start import.
Safe to repeat (already imported bookings are skipped) and can be undone with one button.
